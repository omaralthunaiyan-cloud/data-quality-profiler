How it works

  1. Every column is scored against detectors for email, date, phone, currency, ID, category, and more
  2. The best-matching type becomes that column's inferred schema
  3. Completeness, validity, uniqueness and outliers are measured against it
  4. Nothing is hardcoded — the same engine reads any table
Runs entirely in your browser — nothing is uploaded anywhere.
